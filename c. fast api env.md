```
• Open terminal
  • Run: pip list (check installed packages)

• Navigate to working directory
  • cd Documents
  • mkdir FastAPI
  • cd FastAPI
  • dir (or ls) to confirm directory is empty

• Create virtual environment
  • python -m venv fastapi_env

• Verify environment folder created
  • dir (or ls)

• Activate environment (Windows)
  • fastapi_env\Scripts\activate.bat

• Confirm activation
  • pip list

• Install FastAPI
  • pip install fastapi

• Install Uvicorn
  • pip install "uvicorn[standard]"

• Verify installations
  • pip list

• Deactivate environment
  • deactivate

• Reactivate environment
  • fastapi_env\Scripts\activate.bat

• Confirm again
  • pip list
```
